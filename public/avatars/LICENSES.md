# Demo avatar licenses

The ten demo avatars in this folder were generated from open-source avatar sets
using the DiceBear library (`@dicebear/collection` 9.4.2, MIT). Every set used here
is licensed **CC0 1.0 (public domain)**, so no credit is required and you can use
them in your own apps. The license for each set was read from the package's own
metadata.

| Files | Art style in the app | Set | Creator | License |
| --- | --- | --- | --- | --- |
| `sketch_*.png` | Hand-Drawn Sketch | Open Peeps | Pablo Stanley | CC0 1.0 |
| `portrait_*.png` | Flat Portrait | Lorelei | Lisa Wischofsky | CC0 1.0 |
| `line_*.png` | Line Art | Notionists | Zoish | CC0 1.0 |
| `pixel_*.png` | Pixel Art | Pixel Art | DiceBear | CC0 1.0 |
| `mascot_*.png` | Friendly Mascot | Thumbs | DiceBear | CC0 1.0 |

Sets that need credit (CC BY 4.0) or have their own terms (for example Avataaars, Adventurer,
Micah) were deliberately left out.

The backgrounds in `../backgrounds` were drawn for this project and have no outside license.
